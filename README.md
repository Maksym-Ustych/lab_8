# Лабораторна робота 8 – C++ Builder

Цей репозиторій містить лабораторну роботу 8 з курсу "Об'єктно-орієнтоване програмування" для C++ Builder.  

## Зміст
- **Анкета студента** – форма для введення даних студента
- **Обмін валют** – демонстраційний проект
- **Лабораторна 8.pdf** – виконані завдання та відповіді на контрольні питання

## Мова
Проект створено у **C++ Builder 12**.

## Запуск
Відкрити `.cbproj` файл у C++ Builder та запустити проект.
